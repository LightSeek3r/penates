# Sources de données et licences

Une ligne par source utilisée par l'application. Les mentions de crédit indiquées doivent être respectées. Les lignes prix, contours, équipements, zonage sismique et fond de carte ont été vérifiées le 2026-11-04 ; les lignes des couches ajoutées le 2026-11-06 reprennent la licence inscrite dans la provenance de chaque module du pipeline (`pipeline/settling/layers/`). L'édition, la date de téléchargement et l'empreinte de chaque fichier sont aussi inscrites dans le manifeste de construction. Les couches marquées « prévu » ne sont pas encore publiées sur la carte.

Toute source ci-dessous sous Licence Ouverte impose de citer la source et la date de sa dernière mise à jour ; la mention à afficher figure dans la dernière colonne.
